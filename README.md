# REKSA STIMI

Skeleton aplikasi Platform Rekognisi Pembelajaran Lampau STIMI YAPMI Makassar.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- MongoDB
- Mongoose
- TanStack React Query

## Menjalankan Project

1. Salin `.env.example` menjadi `.env`.
2. Isi `MONGODB_URI` dan `SESSION_SECRET`.
3. Install dependency:

```bash
npm install
```

4. Jalankan development server:

```bash
npm run dev
```

5. Buka `http://localhost:3000`.

## Catatan Fondasi

Tahap ini hanya membuat fondasi: koneksi database, model awal, login sederhana, layout dashboard, dan guard role dasar.
